# Data

Use this folder for tiny sample captures, labels, and notes about datasets.

Avoid committing large raw datasets, long audio recordings, or many camera frames. Instead, document where they are stored and commit small representative samples only when they help explain the project.

## Suggested Layout

```text
data/
|-- README.md
|-- samples/
|   |-- camera/
|   `-- audio/
`-- labels/
```

## Capture Notes To Record

- Date
- Hardware setup
- Firmware commit or build
- Camera resolution / format / frame rate
- Audio sample rate / channels / bit depth
- Lighting and background noise conditions
- Any known issues during capture
